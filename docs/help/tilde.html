Tilde substitution

If the directory name begins with a tilde:

  • ~ - a tilde will be substituted with your home directory
  • ~username - append a username after the tilde and it will be substituted with the home directory of the specified user. If no such user is found, then the original text is left unchanged.

Examples:

  • ~root - the home directory of the user root
  • ~/bin - the subdirectory bin in your home directory
