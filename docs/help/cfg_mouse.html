List of configurable parameters 3/4

Warning: do not change parameters you do not understand. If you are unsure, test the new value before saving the configuration. If any problems occur, reset the parameter to standard value.

MOUSE
This parameter controls the support for a computer mouse. The values are: disabled, enabled:right-handed (default), and enabled:left-handed. A left handed mouse is a mouse with left and right button swapped.
MOUSE_SCROLL
Mouse wheel scrolls the cursror bar by this number of panel lines.
DOUBLE_CLICK
Mouse double click interval in milliseconds.
