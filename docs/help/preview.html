File preview

The file preview panel provides a quick preview of the file contents. A small data block of the file is displayed in the text form. The limit is up to 16 kilobytes or up to 400 lines of text.

Only regular files can be previewed. Files containing null bytes or high ratio of control codes are deemed binary and not displayed.

Press <enter> or ctrl-C to exit the preview panel. There are no other functions defined.
